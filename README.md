# FlashSale

Sistema de simulación de una Flash Sale desarrollado en ASP.NET Core MVC.

## Tecnologías utilizadas

- ASP.NET Core MVC
- C#
- MongoDB
- Apache Kafka
- Docker
- Bootstrap 5

## Funcionalidades

- Gestión de productos.
- Generación de eventos de compra (Individual y Masivo).
- Envío de eventos mediante Kafka Producer.
- Consumo de eventos mediante Kafka Consumer.
- Almacenamiento en MongoDB.
- Dashboard para visualizar los eventos generados.

## Requisitos

- .NET 10
- MongoDB
- Docker Desktop
- Apache Kafka

## Ejecución

1. Clonar el repositorio.
2. Iniciar MongoDB.
3. Levantar Kafka con Docker.
4. Ejecutar la aplicación desde Visual Studio.
5. Acceder a:

```
https://localhost:7036
```
